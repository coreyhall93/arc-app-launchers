# Scripts

This directory contains helper scripts that make building and maintaining launchers easier.

## Planned / Future Scripts

- `convert-favicon-to-icns.sh` — Download a site's favicon and turn it into a proper `.icns` file
- `create-platypus-profile.sh` — Generate consistent Platypus settings
- `test-arc-launch.sh` — Diagnostic script for testing different launch methods
- `install-launcher.sh` — Copy a built `.app` to `/Applications` cleanly and remove quarantine

We'll build these as we go and document them here.
